# CareerQuest - Gamified Learning Platform

## Overview

CareerQuest is a full-stack gamified learning platform that helps students prepare for careers through structured roadmaps, quizzes, AI-powered tools, internships, and job recommendations.

## Features

- User Authentication (JWT)
- Career Roadmaps
- Daily Lectures
- AI Career Advisor
- AI Quiz Generator
- AI Mock Interview
- Resume ATS Checker
- XP & Level System
- Badges & Achievements
- Leaderboard
- Daily Missions
- Internship Recommendations
- Job Recommendations

## Tech Stack

### Frontend
- React.js
- React Router
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JWT Authentication

### AI
- Groq API (Llama Models)
